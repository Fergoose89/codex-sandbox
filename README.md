# codex-sandbox

This repo is for learning how to use Codex through small practical coding exercises.

## Rules
- Keep each project small
- Every project must have:
  - a clear purpose
  - run instructions
  - sample input/output
- Use GitHub Codespaces as the default runtime

## First projects
1. CSV summariser
2. HTML link extractor
3. Council payments parser
4. Cabinet report keyword scanner
